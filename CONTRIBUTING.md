# Как помочь Netacad-Runner

Полезны воспроизводимые баг-репорты, исправления и уточнения инструкции. Посмотрите [открытые Issues](https://github.com/bsanat/NetacadRunner/issues), чтобы дополнить существующее обсуждение.

## Сообщить об ошибке

Откройте [форму Bug report](https://github.com/bsanat/NetacadRunner/issues/new/choose). Укажите версию расширения, курс, шаги до сбоя и последнее состояние журнала. Если известен номер урока или вопроса, добавьте его — так проблему проще повторить.

## Предложить исправление

Один pull request — одна задача. Меняйте исходники в `runner/src` или `extension`; если изменилось поведение, добавьте небольшую проверку в `tests`.

Из корня проекта:

```bash
npm ci
npm test
npm run build
```

При изменении Runner приложите пересобранные `runner/auto-runner.js` и `extension/runner.js`: они нужны для установки без сборки. В описании PR укажите проблему, изменение поведения и выполненные проверки. Результаты на локальном макете и на реальном NetAcad описывайте отдельно.
